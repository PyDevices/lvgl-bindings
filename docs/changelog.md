# Changelog

Each package is released on its own, so the notes live with the release.

- **lvgl-python** (`pydevices-lvgl` on TestPyPI): [GitHub releases](https://github.com/PyDevices/lvgl-python/releases). Its version is the LVGL line plus a counter, such as `9.5.52`.
- **lvgl-bindings** publishes source tags, not releases: [tags](https://github.com/PyDevices/lvgl-bindings/tags).
- **lvgl-micropython** and **lvgl-circuitpython** are built into your firmware from a commit, so they have no versions to list: see their [commits](https://github.com/PyDevices/lvgl-micropython/commits/main) and [commits](https://github.com/PyDevices/lvgl-circuitpython/commits/main).

What's planned next is in the [bindings roadmap](https://github.com/PyDevices/lvgl-bindings/blob/main/ROADMAP.md).
